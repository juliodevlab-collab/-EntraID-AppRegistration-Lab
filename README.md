# -EntraID-AppRegistration-Lab
Authentification et intégration applicative de Microsoft Entra ID
Comprendre comment Microsoft Entra ID permet d'authentifier des applications et de leur accorder l'accès aux ressources Microsoft 365 via Microsoft Graph.

L'objectif n'est pas uniquement de créer une App Registration, mais surtout de comprendre son utilisation dans un environnement professionnel.
